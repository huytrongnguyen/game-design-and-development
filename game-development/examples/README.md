# Examples

Runnable examples for the [Game Development course](../README.md). One folder per module (`NN-topic/`), each a self-contained C# / .NET 10 project with its own xUnit tests. From the course folder:

```bash
dotnet test examples/03-game-loop
```

These are teaching code, kept small and readable, not production code. Start a new example by copying `_template/`.
